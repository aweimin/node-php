# node-php-x

将 PHP 解释器打包进 npm 包，安装后即可在任意目录直接运行 `php` 命令，无需单独配置 PHP 环境变量。

## 安装

全局安装，获得全局 `php` 命令：

```bash
npm install -g node-php-x@next
```

> **为什么用 `@next`**：npm 上此包历史版本采用旧命名规则（`8.314.1`），数值上高于新版的 `8.3.x`。npm 不允许低版本自动占用 `latest` 标签，因此新架构版本通过 `next` 标签发布。不带标签的 `npm install node-php-x` 会装到旧版 `8.314.1`。

本地开发时也可以在项目内链接：

```bash
npm link
```

## 使用

安装后和普通的 PHP CLI 完全一样，所有参数都会原样转发给内置的 PHP：

```bash
php -v                          # 查看版本
php -S 127.0.0.1:8080           # 启动内置开发服务器
php index.php                   # 执行脚本
php -m                          # 查看已加载扩展
```

命令的退出码也会透传，可用于脚本判断执行结果。

## 版本命名

包版本采用 `PHP主版本.PHP次版本.补丁版本` 格式，便于按 PHP 版本区分：

- `8.3.2` → 基于 PHP 8.3，本库第 2 个补丁版本（当前版本，`next` 标签）
- 后续切换到 PHP 8.1 / 8.5 / 8.6 时，包版本相应变为 `8.1.x` / `8.5.x` / `8.6.x`

> 注：npm 上的 `latest` 标签仍指向旧命名规则的最高版本 `8.314.1`（数值上高于 `8.3.x`）。新版本需通过 `node-php-x@next` 安装。

内置的精确 PHP 版本记录在 `package.json` 的 `phpVersion` 字段（当前为 8.3.14），也可通过 `version()` 函数获取。

## 平台支持

PHP 二进制按平台拆分为独立的子包，安装主包时包管理器会根据 `os` / `cpu` 自动只下载匹配的那个：

| 平台 | 子包 |
|---|---|
| Windows x64 | `@node-php-x/win32-x64` |

主包本身只有几 KB 的 JS 入口。目前仅支持 Windows x64，其他平台（Linux / macOS）的子包待补充。

## 说明

- 内置 PHP 8.3.14（Windows x64，ZTS）。
- 当前 `php` 命令名为全局映射，如果系统已安装其他 PHP 且在 PATH 中，可能发生冲突；如需使用其他命令名，可修改 `package.json` 中的 `bin` 字段。
